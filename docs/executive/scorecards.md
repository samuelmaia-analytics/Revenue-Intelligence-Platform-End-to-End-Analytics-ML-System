# Executive Scorecards

## Revenue At Risk

Questions answered:

- how much revenue is exposed to churn risk
- which segments concentrate the highest risk
- where action priority should start

Core metrics:

- high-risk customer share
- weighted revenue-at-risk proxy
- segment-level churn exposure
- top accounts by projected recoverable impact

## Opportunity Board

Questions answered:

- where the highest near-term upside exists
- which actions are economically attractive

Core metrics:

- potential impact
- action mix
- top-10 portfolio impact
- expected ROI by action type

## Segment And Channel Performance

Questions answered:

- which segments perform well or degrade
- which channels deliver efficient growth

Core metrics:

- LTV / CAC
- retention by cohort
- next-purchase probability
- revenue proxy by channel and segment

## Operational Reliability

Questions answered:

- can leadership trust the current cycle's numbers

Core metrics:

- freshness status
- artifact validation status
- active alerts
- run completion status

## Governance And Data Trust

Questions answered:

- which numbers are governed
- whether model outputs are reliable enough for action

Core metrics:

- semantic metric catalog coverage
- calibration status
- drift status
- contract and schema validation health
