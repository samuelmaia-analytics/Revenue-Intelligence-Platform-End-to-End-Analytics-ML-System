# Recurring Analytics Operating Pack

## Objective

Package the recurring operating rhythm for managed analytics delivery.

## Core Artifacts Per Cycle

- `executive_summary.json`
- `insight_draft.json`
- `reliability_report.json`
- `observability_summary.json`
- `alerts_report.json`

## Suggested Monthly Cadence

1. Run the canonical batch pipeline.
2. Review reliability and alerts before circulation.
3. Review executive summary and insight draft with stakeholders.
4. Review action board and scenario deltas.
5. Log threshold changes, metric changes, and backlog items for the next cycle.

## Delivery Surfaces

- executive dashboard
- executive summary export
- reliability report
- API exports for external stakeholders

## Consultant Notes

- treat reliability review as part of the product, not internal-only plumbing
- keep AI drafting assistive and evidence-backed
- preserve the canonical runtime and artifact contracts across every client adaptation
