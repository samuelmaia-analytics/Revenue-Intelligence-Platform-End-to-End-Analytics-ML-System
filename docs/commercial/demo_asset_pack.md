# Demo Asset Pack

## Objective

Create a repeatable set of assets for commercial demos, sponsor reviews, and proposal follow-up.

## Core Assets

- `README.md`
- `docs/executive/one_pager.md`
- `docs/executive/technical_one_pager.md`
- `docs/demo_walkthrough.md`
- `docs/reliability_report.md`
- `docs/commercial/evidence_pack.md`
- `docs/commercial/proposal_template.md`

## Executable Assets

- `scripts/demo_enterprise.ps1`
- `scripts/demo_api_exports.ps1`
- `docker-compose.yml`

## Recommended Demo Flow

1. Start the environment.
2. Show the Streamlit command center.
3. Show the API scorecard and export surfaces.
4. Show reliability and insight artifacts.
5. Close with offers, scope, and operating model.

## Follow-Up Pack

After a demo or discovery call, send:

- executive one-pager
- technical one-pager
- proposal template excerpt
- reliability sample
- implementation checklist
