# Demo Walkthrough

## Objective

Provide a structured commercial and technical walkthrough for client demos, interviews, and proposal support.

## Recommended Sequence

1. Start with the architecture and canonical runtime.
2. Show the command center home and explain the decision layer.
3. Open `Revenue At Risk` and identify where intervention should start.
4. Open `Forecast And Scenarios` and show action-driven upside.
5. Open `Operational Reliability` and explain why the numbers can be trusted.
6. Open `Governance And Trust` and show drift, calibration, and semantic metrics.
7. Call the API export surfaces for executive summary and reliability report.
8. Close with the commercial offers and recurring operating pack.
9. Show the proposal and SOW assets to explain implementation shape.

## Key Messages

- one official runtime
- governed outputs
- decision-ready consumption
- recurring operational discipline
- adaptable delivery model for real clients
