# Reliability Report

## Purpose

Provide a governed operational summary that can be shared in recurring analytics delivery, release reviews, and executive circulation checks.

## Artifact

`data/processed/reliability_report.json`

## What It Includes

- run status and run id
- technical SLA target and freshness status
- runtime duration and slowest stage
- quality counts for duplicates, referential issues, and nulls
- governance status from artifact validation and alerts
- operational readout backed by the governed insight draft

## Why It Matters

This creates a repeatable monthly or weekly operating artifact for managed analytics services. It turns runtime evidence into a portable summary that can be reviewed by operations, analytics leadership, and commercial stakeholders.
