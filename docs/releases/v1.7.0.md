# v1.7.0

## Summary

This release hardens repository governance and delivery operations across CI policy, GitHub workflow documentation, Streamlit deployment guidance, and LGPD-oriented privacy controls.

## Highlights

- added `docs/github_actions_workflows.md` to document workflow triggers, job intent, and failure attribution
- added `docs/lgpd_data_governance.md` with repository-level privacy and LGPD operating controls
- updated governance/CI documentation and README surfaces to reference workflow and privacy policy explicitly
- updated Streamlit private-repository deployment guidance, including runtime pinning (`runtime.txt`) and account-linking troubleshooting
- expanded issue/PR templates with privacy impact prompts for review discipline
- aligned governance tests with the current runtime dependency baseline (`streamlit==1.56.0`)

## Operational Impact

- reviewers can validate CI and GitHub Actions intent without reverse-engineering workflow files
- privacy and data-exposure expectations are explicit for ingestion, exports, and deployment surfaces
- Streamlit Cloud deployment troubleshooting is now documented for private-repo/public-app usage
- repository policy checks now protect the new governance documentation from silent drift
