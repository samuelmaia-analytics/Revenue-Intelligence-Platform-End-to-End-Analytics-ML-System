# Client Handoff Checklist

## Technical Handoff

- environment variables are documented
- runtime and demo commands are verified
- data source mappings are captured
- output artifacts and export surfaces are explained

## Executive Handoff

- leadership users know where to find executive scorecards
- reliability report usage is explained
- scenario and action-board logic is explained
- insight-drafting posture and AI limits are explained

## Operating Handoff

- monthly review rhythm is documented
- incident playbooks are linked
- ownership and escalation path are documented
- backlog and enhancement path are agreed
