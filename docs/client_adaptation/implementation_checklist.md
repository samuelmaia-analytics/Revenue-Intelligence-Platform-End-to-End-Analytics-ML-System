# New Client Implementation Checklist

## Discovery

- identify source systems and owners
- map decision users and operating cadence
- confirm KPI definitions and dispute areas
- define required executive outputs

## Data Foundation

- map source-to-contract fields
- define freshness expectations
- define quality thresholds
- validate joins, grain, and entity keys

## Decision Layer

- define executive scorecards
- define risk and opportunity thresholds
- confirm action taxonomy and approval workflow
- align scenario assumptions with business stakeholders

## Delivery

- configure runtime environment
- run batch pipeline and inspect manifests
- validate dashboard, API, export, and warehouse surfaces
- review incident playbook and handoff expectations

## Acceptance

- validate numbers with business owners
- approve scorecards and narrative
- confirm recurring operating rhythm
- document open risks and next iteration backlog
